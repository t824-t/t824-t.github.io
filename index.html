Projects

WEB APPLICATION

Nutrition Tracker｜栄養管理アプリ

食事・栄養目標・体重を一元管理するWebアプリケーションです。 日々の記録や栄養バランスの可視化を通じて、 継続しやすい栄養管理を目指して開発しました。

Java 17 Spring Boot Spring Security Thymeleaf H2 AWS EC2 nginx

主な機能

  • 食事の登録・編集・削除、検索
  • カロリー・PFCの目標管理
  • 栄養情報のダッシュボード表示
  • 体重記録・推移グラフ
  • ユーザー認証とユーザー別データ管理

工夫した点

  • MVC構成による役割分離
  • Spring Securityによる認証・CSRF対策
  • AWS EC2・HTTPSによる公開運用
  • 画面表示・セキュリティ関連の自動テスト
